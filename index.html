MoreRight

The inverted LessWrong mirror. Every post, argued the other way — in inverted colors, by local models, for laughs. An idea by Utah teapot (@SkyeSharkie).

PARODY: MoreRight mirror — every output on this page argues the opposite of the original post. It is not the author's view.

1. Get a LessWrong post

Fetch uses the LessWrong GraphQL endpoint directly from your browser. If that fails (CORS, offline, moved post), the paste box is the graceful fallback — nothing here needs a server.

2. Configure the two-pass ollama pipeline

If no ollama endpoint answers, Invert falls back to the demo on the built-in sample so you can see the whole flow. Demo output is always labelled demo output.

3. Or queue it on the MoreRight cluster (free, queued)

No ollama of your own? Submit the post above to the MoreRight cluster: a small private cluster that pulls inversion jobs one at a time and runs the same two passes (qwen3:14b → llama3.1:8b). It costs the cluster nothing to serve you, so the price is patience: you get a queue position and a live ETA, and the mirror appears below when it lands.

The ETA is computed from measured job times on the cluster and is recomputed as you watch. If the cluster is offline, no ETA is shown — the job waits and runs when it returns. One job per visitor at a time; the queue holds 20; a full queue says so instead of inventing an ETA. Posts are capped at ~14,000 characters (longer posts are truncated, and you are told) and are deleted a day after the job completes.

Which models, and why two passes

Utah teapot named the tension herself: “for better writing styles you need older models but for higher reasoning abilities you need newer models.” She is right, and that is exactly why MoreRight is a pipeline, not a prompt. Inverting an argument is a reasoning task — you have to find the load-bearing claims, negate them without strawmanning the structure, and re-read the evidence against the original conclusion. Rendering the result is a voice task — fluent, period LessWrong prose. One model is asked to do neither job; each pass gets the model class that is good at its half.

Pass 1 — Invert (newer reasoning models)

  • Default: qwen3:14b — strong reasoning, ~9 GB at ollama's default 4-bit quantization (sizes approximate). Fits fully on the RTX 4080 laptop's 12 GB VRAM, and runs on a 780M iGPU ranch node with 32 GB shared RAM.
    ollama pull qwen3:14b
  • Fallback / explicit-reasoning option: deepseek-r1:14b — the R1-Distill-Qwen-14B; its visible chain-of-thought makes inversion maps easy to audit.
    ollama pull deepseek-r1:14b
  • Small-node option: qwen3:8b or deepseek-r1:8b (~5 GB) — the pick for 16 GB 780M nodes.
    ollama pull qwen3:8b
  • Bigger-laptop stretch: qwen3:32b — better maps on long, dense posts; will spill past 12 GB VRAM into system RAM on the 4080 laptop, so expect it slower, not impossible.

Pass 2 — Render (older, fluent, period-voice models)

  • Default: llama3.1:8b — fluent, steerable, ~5 GB; the safe house style.
    ollama pull llama3.1:8b
  • Period-voice alternative: mistral:7b — Mistral 7B (v0.3), an older-generation model with a drier, more blog-era cadence.
    ollama pull mistral
  • Deep-cut experiment: llama2:13b — Llama 2 era prose; ollama's library notes 13B models want ~16 GB RAM. The 7B (llama2:7b, ~8 GB) is the small-node version. Funniest output, weakest instruction-following — which is part of the experiment.
    ollama pull llama2:13b

Model names and tags verified against ollama.com/library on 2026-11-21: qwen3 (tags include 8b, 14b, 32b), deepseek-r1 (distills include 8b, 14b), llama3.1 (8b), mistral (7B, v0.3), llama2 (7b, 13b). Download sizes are the usual 4-bit approximations, not guarantees.

The process

  1. Fetch. Parse the post ID from the LessWrong URL and pull the post from LessWrong's GraphQL endpoint. On any failure, paste the text instead.
  2. Invert (Pass 1). The reasoning model returns an inversion map only: flipped title, flipped thesis, each load-bearing claim negated, the original's own evidence re-read against its conclusion, and the original structure preserved.
  3. Render (Pass 2). The style model rewrites the post from the map alone — same structure, opposite argument, fluent LessWrong-like voice.
  4. Label. The output is shown beside the original, in inverted colors, under the parody banner. The banner is part of the output, not decoration: it travels with the copy button.
  5. Or queue it. Mode 3 sends the post to the MoreRight cluster queue instead: the server holds the job, a cluster machine pulls it when it reaches the front, and the page polls for the result. Same passes, same banner — the only difference is whose hardware, and the wait.

Honest limits

  • Long posts need chunking by section; this POC sends up to ~14,000 characters and tells you when it has truncated. A production version inverts section by section and stitches.
  • Inversion quality is bounded by Pass 1. A weak map makes a confident, fluent, wrong-shaped mirror — Pass 2 cannot fix a bad map, it can only make it prettier.
  • Satire of an argument is not a refutation of it. MoreRight output is a joke with a method, and the parody labelling is non-negotiable.
  • Fetching is one post at a time, at human pace, from the public GraphQL endpoint.
