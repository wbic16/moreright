# MoreRight

**The inverted LessWrong mirror.** MoreRight takes any LessWrong post and rewrites it
arguing the *opposite* of what it actually argues — presented in inverted colors,
generated by local models, for laughs.

> **Parody, labelled everywhere:** every MoreRight output carries the banner
> *"MoreRight mirror — this post argues the opposite of the original; it is not the
> author's view."* The banner is part of the output, including when you copy it.
> MoreRight is not affiliated with LessWrong or Lightcone, and original posts remain
> their authors'.

## The idea

Utah teapot ([@SkyeSharkie](https://x.com/SkyeSharkie/status/2124129951503045081)):

> "Someone should make an LLM powered version of LessWrong with dark mode inverted
> colors, called MoreRight that mirrors all the posts but edits them to be arguing
> the opposite thing to what they are actually arguing, it'd be hilarious. Although,
> probably difficult because for better writing styles you need older models but for
> higher reasoning abilities you need newer models, hmm."

That last sentence is the design. MoreRight is a **two-pass pipeline**, not a prompt —
each pass gets the model class that is good at its half.

## Run it

No build step, no server, no dependencies. Everything is in one file:

1. Open `index.html` in any browser (double-click it, or serve the folder with
   e.g. `python3 -m http.server`).
2. Paste a LessWrong post URL and hit **Fetch post** — the page pulls the post from
   LessWrong's public GraphQL endpoint. If the fetch fails, paste the post text
   into the fallback box instead.
3. Hit **Invert it → MoreRight** and read the original and the mirror side by side.

**No ollama running?** The page ships with a built-in sample (a short excerpt of
Nathan Young's "Lightcone Commons: what I funded and why") and a pre-written,
clearly labelled **demo mode** — hit *Run the demo* and the whole flow works with
zero network and zero models.

## The two-pass model setup (ollama)

Start ollama (`ollama serve`, default endpoint `http://localhost:11434` — the page's
endpoint and both model names are configurable in the UI), then pull one model per pass:

### Pass 1 — Invert (newer reasoning model)

Produces the argument-inversion map: flipped thesis, each load-bearing claim negated,
the original's evidence re-read against its conclusion, structure preserved.

```sh
ollama pull qwen3:14b        # default — strong reasoning, ~9 GB at 4-bit; fits a 12 GB RTX 4080 fully
ollama pull deepseek-r1:14b  # fallback — R1-Distill-Qwen-14B; visible reasoning makes maps easy to audit
ollama pull qwen3:8b         # small-node option (~5 GB) for 16 GB ranch nodes
```

### Pass 2 — Render (older, fluent, period-voice model)

Rewrites the post from the inversion map alone, in a fluent LessWrong-like voice.

```sh
ollama pull llama3.1:8b      # default — fluent house style, ~5 GB
ollama pull mistral          # period-voice alternative — Mistral 7B (v0.3), drier blog-era cadence
ollama pull llama2:13b       # deep-cut experiment — Llama 2 era prose; wants ~16 GB RAM (llama2:7b for small nodes)
```

Hardware notes: the defaults are sized for the ranch's AMD 780M iGPU nodes
(~16–32 GB shared RAM class) and for a 12 GB RTX 4080 laptop, where `qwen3:14b`
runs fully on-GPU. `qwen3:32b` produces better maps on long, dense posts but will
spill into system RAM on 12 GB VRAM — slower, not impossible.

Model names and tags verified against [ollama.com/library](https://ollama.com/library)
on 2026-11-21: qwen3 (8b, 14b, 32b), deepseek-r1 (8b, 14b distills), llama3.1 (8b),
mistral (7B v0.3), llama2 (7b, 13b). Sizes are the usual 4-bit approximations.

## The process

1. **Fetch** — parse the post ID from the URL; pull the post via LessWrong GraphQL
   (paste fallback on any failure).
2. **Invert** — Pass 1 returns an inversion map only (the page shows it, collapsed,
   so you can audit the reasoning before trusting the render).
3. **Render** — Pass 2 rewrites from the map: same structure, opposite argument.
4. **Label** — output sits beside the original, in inverted colors, under the
   parody banner, with word counts and a copy button that includes the banner.

## Honest limits

- Long posts need chunking by section. This proof of concept sends up to ~14,000
  characters and tells you when it truncates; a production version would invert
  section by section and stitch.
- Inversion quality is bounded by Pass 1. A weak map makes a confident, fluent,
  wrong-shaped mirror — Pass 2 cannot fix a bad map, only make it prettier.
- Satire of an argument is not a refutation of it. MoreRight is a joke with a
  method, and the parody labelling is non-negotiable.
- Fetching is one post at a time, at human pace, from the public endpoint.
